# Diyaverse 2026

A static, mobile-first website for the Business Department, DDU Diwali fest. The site uses plain HTML, CSS and vanilla JavaScript, with no build step or server dependency.

## Before publishing

1. Replace the remaining square-bracket placeholder in `index.html`, `[FEST_HASHTAG]`.
2. The official DDU logo is in `assets/ddu-logo.png`. It is used in the header, hero and link preview.

## Deploy on GitHub Pages

1. Create a GitHub repository and upload `index.html`, `css/`, `assets/` and this README to the repository root.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing the site and the `/ (root)` folder, then save.
5. Wait for the Pages deployment to finish. Open the published URL shown in the Pages settings to check the page on a phone and desktop.

The **Share this site** button creates a WhatsApp message with the current page URL, so use it after the site is published. All local asset paths are relative, so the site works from a GitHub Pages project URL as well as when `index.html` is opened directly.
